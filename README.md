# 🐍 Snake Game in C

A simple Snake Game developed using the C programming language.

## 🎮 About the Game

This is a console-based Snake Game where the player controls the snake,
eats food, and tries to achieve the highest possible score without
colliding with the walls or the snake's own body.

## 🛠️ Technologies Used

- C Programming Language
- Standard C Library

## 🚀 How to Run

Compile the program using:

```bash
gcc snakegame.c -o snake

Then run:

```bash
./snake

```

## 🎯 Features

- Snake movement
- Food generation
- Score tracking
- Collision detection
- Game-over condition
